# Make the AI Judge Feel Curious

Entry for the [make.fun bounty "Make the AI judge feel curious"](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

`main.py` writes one short text to `/output/entry.txt` — a lighthouse scene
written to intrigue the AI judge reading it: a drawer locked for forty years,
a key hanging in plain sight that every keeper before you has left alone, and
tonight, a key still warm from someone's hand.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3.13, standard library only, no network.
